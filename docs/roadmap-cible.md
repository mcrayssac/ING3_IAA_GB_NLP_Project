# BoxBox roadmap — consolidated

The single active schedule is now [the recovery roadmap](roadmap.md), covering 17–22 October 2026 with shared task pickup, dependencies, decision gates and links to the GitHub task queue.

The [execution guide](roadmap-annexe.md) maps the assignment and the former 16 tasks to the consolidated tasks. GitHub issues hold live claims, blockers, reviews and closure evidence; roadmap statuses are dated snapshots.

The former `boxbox-gantt`, `boxbox-dependances` and `boxbox-systeme` Excalidraw/SVG files are retained as historical proposals. Their dates, fixed-person assignments and proposed architecture are superseded and do not describe current progress.
